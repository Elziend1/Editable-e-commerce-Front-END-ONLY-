# Aperture Storefront

A modern, Apple-inspired e-commerce storefront built with React and Tailwind CSS. This project focuses on high-end micro-interactions, a seamless cart experience, and a dynamic theming system.

## Features
- **macOS-style Quick View:** Hover over a product and press `Spacebar` (Desktop) or long-press (Mobile) to open a Quick View modal.
- **Liquid Glass Theme:** A frosted glass UI mode exclusively available on Apple devices (iOS/macOS) via feature detection.
- **Dynamic Theming:** Light, Dark, System, and Glass modes with instant transitions.
- **State Management:** Fully functional shopping cart saved to `localStorage`, complete with quantity adjustments and a smooth side-drawer.
- **Mock Auth & Checkout:** Email/password authentication UI and a simulated payment flow.
- **Store Locator:** Integrated Google Maps with a CSS filter that automatically turns the map dark in Dark Mode.
- **Legacy Fallback:** A graceful fallback page for devices older than iOS 13.

## Tech Stack
- **React (Vite)**
- **Tailwind CSS v4**
- **Lucide / Custom SVG Animations**
